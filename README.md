# lines-of-arts

Бесплатный учебный атлас европейской живописи Ренессанса. Полноэкранный холст для портфолио: шесть пересекающихся направлений, 24 художника, 58 работ и исторические связи с музейными источниками. У каждого мастера минимум две работы; это учебная подборка, а не полный каталог наследия.

## Запуск на Windows

```powershell
cd 'D:\Bussiness\Timeline of Arts'
npm.cmd install
npm.cmd run dev
```

Открыть http://127.0.0.1:5173. Сервер слушает только локальный адрес.

```powershell
npm.cmd run check:data
npm.cmd run check:interface
npm.cmd run build
npm.cmd run preview
```

Предпросмотр сборки: http://127.0.0.1:4173.

## Возможности

- Холст занимает экран; фильтры открываются в модальном окне слева, сведения о художнике или работе — справа.
- Смена детализации: общий вид с направлениями и точками → отдельные линии художников → миниатюры работ при масштабе от 5×. Близкие точки на общем виде объединяются с числом.
- Карточка направления: краткая справка, три ключевые работы с объяснением их учебной ценности, вертикальный список мастеров и кнопка «Открыть направление». На телефоне карточка открывается нажатием.
- При приближении раскрывается направление под указателем. Остальные остаются компактными; отдельные кнопки раскрывают и сворачивают направления. Перестроение строк и камера анимируются; уменьшение движения учитывает системную настройку.
- Кнопки масштаба: шаг 0,2× до 4× и 0,25× выше. Поиск понимает названия на русском, английском, испанском и немецком. Работы на одной линии объединяются, если миниатюрам не хватает места; нажатие открывает список работ мастера.
- Избранное: отдельные списки направлений, художников и картин, хранящиеся в localStorage.
- Настройки: русский, английский, испанский, немецкий; белая, тёплая, тёмная и чёрная темы. Выбор сохраняется локально.
- Колесо масштабирует вокруг указателя; перетаскивание двигает холст. Shift + колесо двигает шкалу горизонтально.
- На сенсорном экране: движение одним пальцем, масштаб двумя. Клавиатура: стрелки, +, -, 0; Escape закрывает окно.
- 10 подтверждённых связей: обучение, работа в мастерской и сотрудничество. Отношение Перуджино и Рафаэля, характер которого обсуждается, скрыто по умолчанию и включается отдельно.
- Адрес выбранной картины сохраняется в параметре `?work=botticelli`.
- Галерея, словарь, музейные источники и страницы репродукций доступны в модальных окнах.

## Данные и границы

`src/data/content.js` — направления, работы, источники и словарь. `src/data/artists.js` — художники и типизированные исторические отношения с источниками. `src/utils/canvas-layout.js` — камера, детализация, отдельные строки и группировка точек. Даты эпох приблизительные; принадлежность к этапу служит учебной навигацией, а не исчерпывающей классификацией. Для многолетних работ точка обозначает представительный год из указанного периода. Включена только живопись, в том числе фрески. Проторенессанс — предыстория, маньеризм — пересекающийся последующий этап. Не утверждается превосходство Ренессанса над другими традициями.

`src/data/additional-works.js` и `work-notes.js` — расширенная подборка, источники и самостоятельные подсказки. `artistIds` связывает произведение с авторами независимо от ID картины; «Крещение Христа» доступно у Верроккьо и Леонардо. При многолетнем создании точка отмечает представительный год. Группировка по направлению художника допускает работы за пределами условных дат эпох.

`src/data/image-manifest.json` — оригинальные URL, страницы Wikimedia Commons, права и даты получения. Репродукции имеют Public domain, CC0 или CC BY 3.0; автор фотографии с CC BY указан в карточке и источниках. Файлы находятся в `public/artworks`. Скрипты загрузки используют Commons и требуют сети; во время просмотра сайт к ним не обращается. `work-images.json` фиксирует вручную выбранные репродукции, включая конкретные панели алтарей и лондонскую «Мадонну в скалах».

Тексты написаны самостоятельно по музейным страницам, доступным из карточек и раздела «Источники». Образцы: [Invaluable](https://www.invaluable.com/blog/art-history-timeline/) и [History of Philosophy — Deniz Cem Önduygu](https://www.denizcemonduygu.com/philo/browse/). Интерфейс не копирует их код и содержание.

Шрифты Prata и Golos Text сохранены локально в `public/fonts` вместе с лицензиями SIL Open Font License. При отсутствии шрифтов используются Georgia и Arial. Изображения, шрифты и данные работают локально; приложение не делает внешних запросов при просмотре. Аналитики, регистрации и cookies нет. Публикация не выполнена.

Стек: React, Vite, Lucide. Сборка — статические файлы в `dist`. Линии художников обозначают годы жизни; для мастеров с неизвестной датой рождения — период от документированной деятельности до смерти, явно отмеченный в подписи. Направление — учебная группировка, а не утверждение, что всё творчество художника принадлежит одному этапу. Изгиб связи не датирует отношение.

Предыдущий шаблон сохранён в `docs/templates/v1-main.jsx.txt` и `docs/templates/v1-global.css.txt`. Для добавления следующей эпохи расширьте данные и диапазон в `src/utils/canvas-layout.js`.

`src/utils/i18n.js` содержит русский/английский словарь, `src/data/languages.json` — локальные испанский и немецкий переводы. Испанский и немецкий подготовлены машинным переводом с редакторскими исправлениями терминов, имён и найденных ошибок; профессиональная лингвистическая вычитка не проводилась. Скрипты `generate-languages.mjs` и `finish-translations.mjs` предназначены только для разработки, не для работы сайта. Избранное и настройки сохраняются на текущем устройстве и в текущем браузере; синхронизации нет.
